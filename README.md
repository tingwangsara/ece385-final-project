# Pseudo 3D Driving Simulator
A windshield view pseudo 3D driving simulator with steering wheels plus gas & brake padels to control speed and direction, featuring curvatures, scenary and a start up screen.
## How to run?
- First, connect all the hardware, have the steering wheel connected to the laptop and then connect the laptop to FPGA board's USB port, this will allow the laptop to send direction and speed signals to the FPGA through UART. Then have the monitor connected to the FPGA board through HDMI, and connect the FPGA board to the laptop.
- Second, run Vitis and program board, then run Pythond code to load sky background
- Third, when sky background is loaded, hit reset and start game
